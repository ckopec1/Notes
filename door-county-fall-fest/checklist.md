# Door County Fall Fest Camping — RTT Prep Checklist

Trip target: October 15, 2026  
Vehicle: 2014 Chevrolet Silverado 1500 Crew Cab 4x4, 5.3L, 5'8" bed  
Camping goal: move from Napier truck-bed tent to a fast hard-shell rooftop tent setup without overbuilding the truck before the trip.

## Priority 1 — Rooftop tent + rack

- [ ] Choose/buy RTT
  - Current preferred direction: hard-shell clamshell/wedge, 2-person
  - Favor roughly 51"+ sleeping width for two people
  - Inspect used tent for shell cracks, damaged hinges/struts/latches, torn fabric/mesh, zipper issues, mildew/water intrusion, bent mounting rails, damaged ladder
  - Confirm mattress, ladder, and all original mounting hardware are included
  - Confirm heater/duct port if relevant
- [ ] Choose/buy Silverado bed rack or low crossbars
  - Must fit 2014 Silverado 1500 5'8" bed
  - Dynamic rating must exceed RTT weight
  - Static rating must comfortably support RTT + 2 adults
  - Prefer low-profile / cab-height mounting
  - Target 30"+ front-to-rear crossbar spacing when compatible with RTT instructions
- [ ] Install rack
  - Center and square rack on bed rails
  - Torque all mounting hardware to manufacturer spec
- [ ] Mount RTT
  - Slight forward bias is OK if tent is longer than 5'8" bed
  - Confirm tailgate opens fully
  - Confirm ladder deploys without hitting truck
  - Torque all RTT clamps/bolts to spec
- [ ] Road-test
  - Drive 20–30 miles
  - Listen for movement/rattles
  - Re-torque rack and RTT hardware
- [ ] Practice one full setup + teardown at home
  - Ideally once after dark

## Priority 2 — Warm sleeping setup

- [ ] Sleeping bags / comforters appropriate for expected fall temperatures
- [ ] Extra warm blanket
- [ ] Fitted sheet / mattress cover
- [ ] Pillows
- [ ] Insulation beneath mattress if RTT mattress feels cold
- [ ] Heated mattress pad
- [ ] Electric space heater as an optional shore-power cold-weather backup
  - Use only while awake / to preheat the RTT
  - Keep well clear of tent fabric, bedding, and other combustibles
  - Place on a stable surface with tip-over and overheat protection
  - Use campground/GFCI shore power; do not plan to run it from the battery station
  - Turn it off before sleeping or leaving the tent
- [ ] Warm sleep clothes / socks / beanie
- [ ] Small entry mat or shoe bin for bottom of ladder
- [ ] Keep wet shoes outside sleeping area
- [ ] Battery-powered CO detector if using a diesel heater later
- [ ] Never place a combustion heater inside the RTT; heater and exhaust stay outside

## Optional before this trip — Portable power

A ~1 kWh LiFePO4 power station is sufficient for this camping setup.

Primary uses:
- Heated mattress pad
- Phones
- Lights
- Laptop / small electronics
- Future 12V fridge

Do not delay the RTT install just to finish the electrical system.
